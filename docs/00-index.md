## 当前项目状态

- 后端：Spring Boot 3 + PostgreSQL + pgvector + MinIO。
- 前端：Vite + React + TypeScript。
- 部署：本地开发推荐 Docker 启动依赖服务，Spring Boot 和 Vite 本机启动。
- 当前阶段：MVP 已可运行，正在向生产级标准逐步演进。

## 文档维护原则

- 接口、表结构、配置项变更后，同步更新对应文档。
- 不在文档中写真实密钥、token、用户密码。
- 后续规划和当前已实现能力必须区分清楚。
- 重大架构调整需要先更新 `02-architecture.md` 和 `12-roadmap.md`。
