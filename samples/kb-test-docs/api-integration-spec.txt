开放接口接入说明

一、认证方式
第三方系统调用开放接口时，需要在请求头中携带 Authorization: Bearer <access_token>。
access_token 由平台签发，有效期为 2 小时。过期后需要使用 refresh_token 换取新的 access_token。

二、幂等要求
创建订单、发起退款、提交工单等写操作必须携带 Idempotency-Key 请求头。
同一个 Idempotency-Key 在 24 小时内重复提交时，系统应返回第一次处理结果，避免重复创建业务数据。

三、分页规则
列表接口统一使用 pageNo 和 pageSize 参数。
pageNo 从 1 开始，pageSize 最大值为 100。超过最大值时，服务端按 100 处理。

四、错误码
400 表示请求参数错误。
401 表示 token 缺失、过期或无效。
403 表示当前调用方没有权限访问资源。
404 表示资源不存在或已删除。
429 表示调用频率超过限制。
500 表示服务端处理异常。

五、回调通知
平台向第三方系统发送回调时，会携带 X-Signature 签名头。
第三方系统必须校验签名，防止伪造通知。
如果第三方返回非 2xx 状态码，平台会按照 1 分钟、5 分钟、30 分钟、2 小时的间隔重试。

六、安全建议
生产环境必须使用 HTTPS。
access_token、refresh_token、签名密钥不得写入前端代码或公开仓库。
调用日志需要脱敏，避免记录完整 token、身份证号、银行卡号和手机号。
